# 🚀 GRAVITY STATION: 198X

Пиксельный ретро-платформер с загадками и инверсией гравитации в эстетике Sci-Fi 80-х.

---

## 🕹️ Требования и запуск

### 1. Требования
* **Python 3.8+**
* Библиотека **Pygame**:
```bash
pip install pygame
```

### 2. Запуск игры

* **Windows:** запустите файл **`run_game.bat`** (или через консоль: `python main.py`)
* **macOS / Linux:**
```bash
python3 main.py
```

---

## 🎮 Управление

| Действие | Клавиши |
|---|---|
| **Движение влево / вправо** | `A` / `D` или `←` / `→` (Стрелки) |
| **Прыжок** | `W`, `ПРОБЕЛ` или `↑` (Стрелка вверх) |
| **Инверсия гравитации** | `G`, `SHIFT`, `Z` или `C` *(когда стоите на полу или потолке)* |
| **Рестарт уровня** | `R` *(мгновенный сброс, если зашли в тупик)* |
| **Звук и музыка (Вкл/Выкл)** | `M` |
| **CRT-фильтр (сканлайны)** | `F1` |
| **Пауза / Выход** | `ESC` |

## 🧩 Механики загадок

1. **Инверсия гравитации:** 
   - Нажатие `G` или `SHIFT` меняет вектор притяжения (пол становится потолком и наоборот).
   - Инвертировать гравитацию можно только стоя на твёрдой поверхности — в полёте перевернуть мир нельзя!
2. **Антигравитационные ящики:**
   - Ящики также подчиняются текущему вектору гравитации.
   - Их можно толкать для преодоления препятствий, нажимать ими кнопки или блокировать смертоносные лучи.
3. **Нажимные плиты и гермодвери:**
   - Плиты на полу (`S`) или потолке (`T`) активируют и открывают защитные переборки (`D`).
   - Если сойти с плиты, дверь закроется, поэтому вам понадобится ящик!
4. **Оптические лазерные барьеры:**
   - Высокоэнергетические лучи смертельны при контакте.
   - Лучи можно перекрывать физическими объектами (ящиками).
5. **Шлюз эвакуации (Портал):**
   - Достигнув финального шлюза сектора, вы переходите на следующий уровень.

## 🗺️ Сектора (Уровни)

1. **Sector 1: Boot Sequence** — Знакомство с ходьбой, прыжками и преодолением ловушек через смену гравитации на потолок.
2. **Sector 2: Weight & Measure** — Использование физических ящиков для фиксации нажимных плит.
3. **Sector 3: Ceiling Logistics** — Перенос и толкание ящиков в условиях инвертированной потолочной гравитации.
4. **Sector 4: Optical Barrier** — Обход лазерных барьеров и их блокировка ящиками.
5. **Sector 5: Reactor Escape** — Финальный сложный сектор, объединяющий все механики станции.

## 🛠️ Особенности реализации
- **Движок:** Python 3 + Pygame.
- **Полная автономность:** все спрайты, физика, система частиц и 8-битная chiptune-музыка генерируются процедурно в коде (внешние картинки и аудиофайлы не требуются).
